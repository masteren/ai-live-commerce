## 2. 发表/面试怎么用
- **30 秒版**:README 开头两行 + 架构图。
- **3 分钟版**:「工夫した点」的 4 条,每条按「问题 → 怎么发现 → 怎么解决 → 怎么验证」讲。第 1 条(超卖)最有故事性。
- **被深挖时**:打开 sequence.md 对着图讲流程;被问表设计就打开 er.md(快照、逻辑删除、会话表分离)。

## 3. 要注意
- 文档要和代码一致。以后改了功能,记得同步改 README 的数字(测试件数等)和图。
- 「工夫した点」里写的内容,面试官一定会追问 → 对应的学习笔记 01〜05 要能讲出来。
